Paste. The next command is already waiting.

Clipboard Next is a tiny app for macOS and Windows that queues your demo commands and prompts. With paste detection enabled, every ⌘V on macOS or CtrlV on Windows loads the next one, so you never alt-tab back to your notes on stage.

Available for macOS and Windows 11.

    Small app, presenter-grade details
    
      
    
        
    
          
    ⏱ Adjustable timing
    
          
    Choose how long to wait after a paste before the next snippet loads: 0.1 to 3 seconds. Slow down for apps that read the clipboard late.
    
        
    
        
    
          
    📝 Markdown import
    
          
    Paste your script and preview every candidate in order. Split code blocks line by line, or keep multiline blocks intact.
    
        
    
        
    
          
    ✅ Visible confirmation
    
          
    The menu bar icon or system tray icon and the optional draggable badge flash when a paste is detected, without stealing focus.
    
        
    
        
    
          
    🛡 Safe by default
    
          
    Copy something else mid-demo and the queue pauses instead of overwriting it. Commands are never run, and the app never presses a key for you.
    
        
    
        
    
          
    ⏭ Manual control
    
          
    Pause, resume, skip with Next, or Start Here from any snippet. It works without paste detection, too.
    
        
    
        
    
          
    🔒 Local only
    
          
    No accounts, telemetry, or network connections. Optional paste detection uses a listen-only keyboard monitor and never records what you type.

    Windows
    Available
    
          
    Recommended for your device
    
          
    A native Windows app with the same queue, Markdown import, paste detection, and floating badge.
    
          
    Get it from Microsoft Store
    
          
    Requires Windows 11 21H2 or later. Supports x64 & ARM64. Install and receive updates through the Microsoft Store.
    
          
    Turn on paste detection in the editor, tray popup, or Settings to advance after CtrlV. Enable Terminal paste shortcuts in Settings to also detect CtrlShiftV and ShiftInsert.
    
        
    
      
    
    
    

    
    
      
    Your clipboard stays yours
    
      
    Clipboard Next stores your queue locally at ~/Library/Application Support/ClipboardNext on macOS, or in the app's own storage at %LOCALAPPDATA%\ClipboardNext on Windows. It never uploads anything, never runs what you paste, and pauses when another app changes the clipboard's text.
