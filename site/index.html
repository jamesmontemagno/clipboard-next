Paste. The next command is already waiting.

Clipboard Next is a tiny macOS menu bar app that queues your demo commands and prompts. Every ⌘V loads the next one, so you never alt-tab back to your notes on stage.

    Small app, presenter-grade details
    
      
    
        
    
          
    ⏱ Adjustable timing
    
          
    Choose how long to wait after a paste before the next snippet loads: 0.1 to 3 seconds. Slow down for apps that read the clipboard late.
    
        
    
        
    
          
    📝 Markdown import
    
          
    Paste your script and preview every candidate in order. Split code blocks line by line, or keep multiline blocks intact.
    
        
    
        
    
          
    ✅ Visible confirmation
    
          
    The menu bar icon and the optional draggable badge flash when a paste is detected, without stealing focus.
    
        
    
        
    
          
    🛡 Safe by default
    
          
    Copy something else mid-demo and the queue pauses instead of overwriting it. Commands are never run, and Return is never pressed.
    
        
    
        
    
          
    ⏭ Manual control
    
          
    Pause, resume, skip with Next, or Start Here from any snippet. It works without paste detection, too.
    
        
    
        
    
          
    🔒 Local only
    
          
    No accounts, telemetry, or network. A listen-only keyboard monitor watches for ⌘V and nothing else.

    macOS
    Available
    
          
    Install with Homebrew:
    
          
    
            
    brew tap jamesmontemagno/clipboard-next https://github.com/jamesmontemagno/clipboard-next
brew install --cask clipboard-next
    
            
          
    
          
    Or download the signed, notarized app from GitHub Releases.
    
          
    Requires macOS 14 Sonoma or later. For automatic advancing, allow Clipboard Next under Privacy & Security → Input Monitoring.

    Windows

    Your clipboard stays yours
    
      
    Clipboard Next stores your queue locally at ~/Library/Application Support/ClipboardNext. It never uploads anything, never runs what you paste, and stops when another app takes over the clipboard.
